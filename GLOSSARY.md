# Glossary (simple word list)

| Word | Plain meaning |
|------|----------------|
| **`.xzm` module** | A read-only squashfs app pack (Porteus-style idea) |
| **pman** | Small helper in this repo to build/mount/remove modules (not Nemesis `pman`) |
| **squashfs** | Compressed read-only filesystem used inside `.xzm` files |
| **OpenRC** | The service starter (instead of systemd). Uses `rc-update` / `rc-service` |
| **pacman** | The Artix/Arch package installer |
